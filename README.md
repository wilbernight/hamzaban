# هم‌زبان (Hamzaban)

ترجمه‌ی روان ایمیل‌ها به فارسی در Thunderbird و دوبله‌ی فارسی همزمان ویدیوها در Chrome —
همه‌چیز **آفلاین و روی همین مک** اجرا می‌شود؛ متن ایمیل‌ها و صدای ویدیوها به هیچ سروری فرستاده نمی‌شود.

## اجزا

| بخش | کار | مدل |
|---|---|---|
| موتور محلی (`engine/`) | سرویس پس‌زمینه روی `127.0.0.1:17860` | — |
| ترجمه | هر زبانی → فارسی | TranslateGemma گوگل (۱۲B برای ایمیل، ۴B برای دوبله) از طریق Ollama |
| تشخیص گفتار | صدای ویدیو → متن زمان‌دار | Whisper large-v3-turbo (MLX، روی GPU مک) |
| صدای فارسی | متن فارسی → گفتار | ParSiGo / pocket-tts-farsi-v2 ([nimaone/persian_tts](https://github.com/nimaone/persian_tts)) |
| افزونه‌ی Thunderbird (`thunderbird/`) | دکمه‌ی «ترجمه فارسی» بالای هر ایمیل | — |
| افزونه‌ی Chrome (`chrome/`) | دکمه‌ی «دوبله‌ی فارسی» روی هر ویدیو + گرفتن لینک | — |

## ساختار مخزن

| پوشه/فایل | چیست |
|---|---|
| `engine/` | موتور پایتون (FastAPI)، workerهای صدا، آزمون‌ها |
| `chrome/` | افزونه‌ی Chrome (Manifest V3) — همین پوشه را Load unpacked کنید |
| `thunderbird/` | افزونه‌ی Thunderbird — محتوای پوشه را zip کنید و پسوند را `.xpi` بگذارید (یا از Releases بگیرید) |
| `menubar/` | برنامه‌ی نوار بالای مک (Swift) |
| `install.sh`, `uninstall.sh` | نصب و حذف روی مک |
| `HANDOFF.md` | سند فنی کامل: معماری، تصمیم‌ها، آزمون‌ها، مشکلات شناخته‌شده |
| `WINDOWS.md` | **راهنمای ساخت نسخه‌ی ویندوز** |

فایل آماده‌ی هر دو افزونه در بخش [Releases](https://github.com/wilbernight/hamzaban/releases) هم هست.

## نصب (مک، Apple Silicon)

```bash
git clone https://github.com/wilbernight/hamzaban.git
cd hamzaban
./install.sh
```

پیش‌نیاز: [Homebrew](https://brew.sh). اسکریپت Ollama، uv، مدل‌ها (حدود ۱۲ گیگ) و سرویس پس‌زمینه را نصب می‌کند.
صدای پیشنهادی اُمنی جداگانه نصب می‌شود: `HAMZABAN_OMNI=1 ./install.sh`.

برای ویندوز: [WINDOWS.md](WINDOWS.md).

بعد:

- **Thunderbird:** منوی ☰ ← Add-ons and Themes ← چرخ‌دنده ← Install Add-on From File ← فایل
  `~/Library/Application Support/Hamzaban/extensions/hamzaban-thunderbird.xpi`
- **Chrome:** `chrome://extensions` ← Developer mode ← Load unpacked ← پوشه‌ی
  `~/Library/Application Support/Hamzaban/extensions/chrome`

## استفاده

**ایمیل:** ایمیل را باز کنید و دکمه‌ی «ترجمه فارسی» را در نوار بالای ایمیل بزنید. ترجمه همان‌جا بالای متن اصلی
نوشته می‌شود؛ «خواندن» آن را با صدای فارسی می‌خواند. روی هر متن انتخاب‌شده هم کلیک راست ← «ترجمه‌ی متن انتخاب‌شده».
ترجمه‌ی خودکار همه‌ی ایمیل‌های غیرفارسی را از تنظیمات افزونه روشن کنید.

**ویدیو:** روی هر ویدیو (یوتیوب، ویمئو و…) نشانگر را ببرید و «دوبله‌ی فارسی» را بزنید، یا لینک را در پنجره‌ی افزونه
بدهید. دوبله جلوتر از جایی که تماشا می‌کنید آماده می‌شود و هر جمله دقیقاً سر زمان جمله‌ی اصلی پخش می‌شود؛ اگر
به جایی رسیدید که هنوز آماده نیست (مثلاً اول کار یا بعد از جلو زدن)، ویدیو چند ثانیه صبر می‌کند تا همگام بماند.

**Udemy و سایت‌های قفل‌دار:** صدای ویدیوهای Udemy قفل (DRM) است، برای همین دوبله‌ی Udemy از روی
زیرنویس خود درس ساخته می‌شود؛ افزونه زیرنویس را با همان حسابی که در مرورگر وارد شده‌اید برمی‌دارد. درسی که
دکمه‌ی CC ندارد قابل دوبله نیست. هر سایتی که زیرنویس استاندارد (`<track>`) داشته باشد هم همین‌طور کار می‌کند.

**حالت نمایش:** در پنجره‌ی افزونه بین «دوبله + زیرنویس»، «فقط دوبله» و «فقط زیرنویس» انتخاب کنید. حالت
«فقط زیرنویس» صدا نمی‌سازد و خیلی سریع‌تر آماده می‌شود.

**اصطلاحات برنامه‌نویسی:** ترجمه‌ی لفظی اصطلاح‌ها («رابط»، «ادغام»، «مستقر کنید»، «حافظه پنهان») با واژه‌ای که
برنامه‌نویس‌ها به کار می‌برند («اینترفیس»، «مرج»، «دیپلوی کنید»، «کش») عوض می‌شود. واژه‌های دلخواه خودتان را در
`~/Library/Application Support/Hamzaban/glossary.txt` بنویسید؛ بعد از ذخیره فوراً اعمال می‌شود:

```
service container = سرویس کانتینر = ظرف سرویس، محفظه‌ی سرویس
```

صدای فارسی هم کلمه‌های انگلیسی و نام فایل‌ها را همان‌طور که برنامه‌نویس‌ها می‌گویند می‌خواند
(`PaymentGateway.php` ← «پیمنت گیت‌وی دات پی‌اچ‌پی»، `API` ← «ای‌پی‌آی»).

## چرا «آموزش» لازم نشد

مدل‌ها از قبل روی میلیاردها جمله آموزش دیده‌اند. TranslateGemma مخصوص ترجمه تنظیم شده و در آزمون‌های ترجمه
نسخه‌ی ۱۲B آن از Gemma 3 27B هم بهتر است. هم‌زبان خروجی را با قواعد نگارش فارسی (نیم‌فاصله‌ی «می‌» و «ها»،
«ی/ک» فارسی، ویرگول و علامت سؤال فارسی، اعداد فارسی) و واژه‌نامه‌ی ۴۵۳ هزار واژه‌ای
[persian-writing](https://github.com/ali2000hos/persian-writing) مرتب می‌کند. اگر بعداً بخواهید سبک ترجمه دقیقاً مثل خودتان شود، می‌شود
مدل را با چند صد نمونه‌ی ترجمه‌ی خودتان fine-tune (LoRA) کرد.

## دستورهای مفید

```bash
# وضعیت موتور
curl -s http://127.0.0.1:17860/api/health
# راه‌اندازی دوباره
launchctl kickstart -k gui/$(id -u)/com.hamzaban.engine
# لاگ
tail -f ~/Library/Application\ Support/Hamzaban/logs/engine.log
# تست منطق (بدون مدل)
python3 -m unittest discover -s engine/tests
```

تنظیمات موتور (مدل‌ها، پورت، صدای پیش‌فرض) در `~/Library/Application Support/Hamzaban/config.json` است.
برای حذف کامل: `./uninstall.sh`
